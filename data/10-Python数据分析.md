# Python 数据分析

## NumPy 数组

ndarray 是同类型的多维数组，内存连续，支持向量化运算，避免了 Python 循环的解释器开销。广播机制允许形状不同的数组按规则自动对齐后进行运算。轴的概念对应数组的维度，沿轴求和、求均值是最常用的聚合操作。改变形状时 reshape 返回视图，而花式索引和布尔索引返回副本，对副本的修改不会影响原数组，这是初学者最容易踩的坑。

## Pandas 核心结构

Series 是带标签的一维数组，DataFrame 是带标签的二维表格。读取数据用 read_csv、read_excel，写入用 to_csv。查看数据用 head、info、describe，其中 describe 能快速给出数值列的计数、均值、标准差和分位数。选取数据优先使用基于标签的 loc 和基于位置的 iloc，避免链式索引，链式索引可能返回副本导致赋值不生效。

## 数据清洗

缺失值用 isna 检测，处理方式有删除、填充固定值、填充均值中位数和前后向填充，选择取决于缺失比例和缺失机制。重复值用 duplicated 检测后 drop_duplicates 删除。异常值可以用分位数法或三倍标准差法识别，处理前要判断是录入错误还是真实存在的极端值。类型不一致要先 astype 转换，日期列用 to_datetime 解析后才能做时间运算。

## 分组聚合与表连接

分组聚合用 groupby 后接聚合函数，或用 agg 对不同列指定不同聚合方式。透视表 pivot_table 可以快速做交叉统计。表连接用 merge，需要理解内连接、左连接、右连接和外连接的区别，连接键的数据类型必须一致，否则会静默地匹配不上。纵向拼接用 concat，横向对齐用 join。

## 可视化

matplotlib 是最基础的绘图库，pyplot 提供类似 MATLAB 的接口，图形由画布、坐标系和艺术家对象组成。seaborn 基于 matplotlib，默认样式更美观，能直接绘制分布图、箱线图、热力图和相关矩阵。探索性分析阶段建议先画单变量分布和目标变量关系图，再考虑多变量交互。图表要标注坐标轴名称和单位，避免让读者猜测。

## 网络数据采集

requests 库用于发送 HTTP 请求，需要处理超时、重试、请求头和编码。解析 HTML 常用 BeautifulSoup，复杂场景可以用 XPath。采集时必须遵守网站的 robots 协议，控制请求频率，设置合理的 User-Agent。动态渲染的页面需要分析接口或用无头浏览器。采集到的数据同样要做去重和清洗，不能直接进入分析流程。
